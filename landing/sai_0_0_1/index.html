Что закрывает Sai

Sai забирает на себя первичную аналитику уровня BSA, Product/Project менеджера и Team Lead: структурирует хаотичную идею и превращает её в понятную карту разработки.

  • Быстрый старт из глобального AI-чата
  • Визуализация на бесконечном холсте
  • Изолированные контексты чатов по узлам
  • Гибкий экспорт ТЗ по выбранным деревьям

Три дерева — единая система мышления

При первой синхронизации Sai формирует три взаимосвязанных дерева. Дальше изменения применяются вручную по кнопке «Синхронизация», чтобы пользователь полностью контролировал каскад.

Дерево функционала

Главное ядро продукта: что именно должен уметь сервис и зачем это пользователю.

Дерево разработки

Roadmap реализации: архитектура, технологии, этапы сборки и технические зависимости.

Дерево бизнес-логики

Пользовательский путь от первого касания до целевого действия и ценности продукта.

Функции MVP

Infinite Canvas

Dot-grid фон, плавный pan/zoom, drag & drop узлов и связи кривыми Безье.

Изолированные чаты

Каждый бокс живёт в собственном контексте: только нужный узел и его локальная история.

BYOK-подключение API

Ты сам задаёшь API Key и Base URL для OpenAI-совместимых провайдеров (например, DeepSeek).

Локальное хранение

`tree.json` + `chats/*.md` в директории проекта — прозрачно, офлайн-first и под твоим контролем.

Roadmap v0.0.1 → v0.0.7

  1. Stage 1: базовое окно и темная тема
  2. Stage 2: движок холста и навигация камеры
  3. Stage 3: узлы, порты и связи
  4. Stage 4: сохранение/загрузка в `tree.json`
  5. Stage 5: асинхронный LLM worker
  6. Stage 6: контекстные чаты узлов
  7. Stage 7: генератор итогового ТЗ

Технологический стек

Python 3.12+, PySide6 и Scene Graph-подход на базе `QGraphicsScene` + `QGraphicsView`. Никакого Electron/Tauri в ядре MVP.

  • Python
  • PySide6
  • QGraphicsScene
  • QThreadPool
  • Markdown Export
  • Catppuccin Dark
