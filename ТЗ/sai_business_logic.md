## 1. Проекты и файловая структура

| Вопрос | Решение |
|--------|---------|
| Вложенные проекты | Не нужно. Экспорт/импорт проектов — да |
| Автосохранение | Предупреждение при выходе с несохранёнными изменениями. В меню — опция включения/отключения автосохранения |
| Бэкапы | Кнопка отката не нужна. Для отката достаточно Ctrl+Z |

## 2. Три дерева — синхронизация и связи

| Вопрос | Решение |
|--------|---------|
| Режим синхронизации | Для всех трёх деревьев сразу |
| Каскадирование | ИИ предлагает изменения для смежных деревьев → пользователь подтверждает |
| Меж-деревья связи | Да. Отдельный тип визуальных боксов-мостов со стрелками, ведущими на узлы в других деревьях |

## 3. Чат и контекст

| Вопрос | Решение |
|--------|---------|
| Ручное прикрепление узлов | Да, можно. Память чата остаётся изолированной (только свой узел) |
| Глобальный чат | Может изменять узлы, не только генерировать новые |
| Хранение сообщений | 30 дней по умолчанию, настраивается в settings |

## 4. Экспорт

| Вопрос | Решение |
|--------|---------|
| Форматы | PDF, Markdown, PNG |
| Кастомные шаблоны | Да, возможность выбирать формат экспорта |

## 5. ИИ-провайдеры

| Вопрос | Решение |
|--------|---------|
| Несколько ключей | Да. Быстрый свитчер провайдера прямо в панели чата (как референс) |
| Тарификация/расход токенов | Да, показывать |

## 6. Рабочий процесс

| Вопрос | Решение |
|--------|---------|
| Статусы узлов | Гибко, при необходимости. Без автоматического принудительного перехода |
| Шаблоны проектов | Да. Возможность создать шаблон из текущего проекта и сохранить |
| Метрики | Минимально. Общее количество узлов и базовое распределение |

## Ключевые решения для архитектуры

1. **Inter-tree connections** — новый тип сущности (cross-tree edge), отображается как специальный бокс-мост
2. **Global Chat mutation** — глобальный чат может изменять узлы напрямую (не только brainstorming JSON)
3. **Provider Quick Switcher** — переключение модели/провайдера прямо в интерфейсе чата
4. **Export format selection** — пользователь выбирает формат (PDF/MD/PNG) в ExportDialog
5. **Template system** — сохранение/загрузка шаблонов проектов
6. **Autosave toggle** — опция в меню, окно подтверждения при выходе
7. **Token usage display** — минимальный счётчик расхода
