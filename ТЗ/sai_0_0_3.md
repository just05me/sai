## 1. Описание продукта

**Sai** — нативное десктопное приложение с открытым исходным кодом (Open Source), реализующее концепцию **ИИ-кофаундера и архитектора проектов**.

Продукт автоматизирует первичную аналитическую работу, традиционно выполняемую BSA, Product/Project менеджерами и Team Lead-ами:

- Перевод абстрактной идеи в формализованную структуру (функциональное дерево)
- Декомпозиция функционала на модули, узлы и связи
- Построение Roadmap и архитектурного плана
- Генерация пользовательского пути (User Journey)
- Автоматическое составление полноценного технического задания (Markdown)

Sai не заменяет разработку кода — он заменяет этап **проектирования и аналитики**, делая его наглядным, связным и управляемым через ИИ.

### 1.1. Ключевая ценность

- **Соло-фаундеры** получают «продуктовый отдел в коробке» без найма BSA и PM
- **Вайбкодеры** перестают тонуть в хаосе идей и получают структуру
- **Команды** ускоряют этап предварительного анализа в 5–10 раз

## 2. Целевая аудитория и позиционирование

### 2.1. Аудитория

| Сегмент | Боль | Решение Sai |
|---------|------|-------------|
| Соло-фаундеры | Нет команды для аналитики, идеи остаются идеями | ИИ-архитектор, который ведет от идеи до ТЗ |
| Вайбкодеры | «Чистый лист», отсутствие структуры, потеря фокуса | Визуальное дерево + контекстные чаты по узлам |
| Малые команды (2–5 чел) | Нет BSA/PM, требования размыты | Декомпозиция и Roadmap автоматически |
| Open Source проекты | Нет формального ТЗ для контрибьюторов | Генерация документации из дерева |

### 2.2. Позиционирование

- **Платформа:** Нативное десктопное приложение
- **MVP-платформа:** Linux (Ubuntu 22.04+)
- **Целевые платформы после MVP:** Windows, macOS
- **ИИ-модель:** BYOK (Bring Your Own Key) — пользователь подключает свой API Key
- **Лицензия:** Open Source (LGPL / MIT — фиксируется отдельно)
- **Эстетика:** Цифровой журналинг (Scrapbook Aesthetic), инженерная эстетика редакторов кода, темная тема (базовая), светлая тема (опционально)

### 2.3. Анти-позиционирование (что Sai НЕ является)

- ❌ Не IDE — не предназначен для написания кода
- ❌ Не Notion / Obsidian — не система заметок общего назначения
- ❌ Не Jira / Linear — не трекер задач для команды
- ❌ Не Miro / Figma — не универсальная доска для брейнштормов

## 3. Технологический стек

### 3.1. Базовый стек (MVP)

| Компонент | Технология | Обоснование |
|-----------|-----------|-------------|
| Язык | Python 3.12+ | Экосистема AI/ML, кроссплатформенность |
| GUI | PySide6 (Qt for Python) | Официальные биндинги Qt6, LGPL-лицензия |
| 2D-движок | QGraphicsScene + QGraphicsView | Максимальная производительность для графов |
| Архитектура | Scene Graph + Signals/Slots | Никаких веб-паттернов |
| Асинхронность | QThreadPool + QRunnable | Фоновые запросы к API без блокировки UI |
| Стилизация | QSS (Qt Style Sheets) | Аналог CSS для нативного UI |
| Анимации | QPropertyAnimation (opacity/color only) | 60+ FPS без heavy frame-by-frame |

### 3.2. Зависимости (Python packages)

```
pyside6>=6.7.0           # Qt for Python
httpx>=0.27.0            # HTTP-клиент для API LLM (асинхронный)
pydantic>=2.0.0          # Валидация данных и схем JSON
orjson>=3.9.0            # Быстрый JSON (опционально)
```

│  │  │ (nodes,     │ │(tree.json│ │ (contexts,       │   │   │
│  │  │  edges,     │ │ + chats/ │ │  sessions,       │   │   │
│  │  │  hierarchy) │ │  I/O)    │ │  @ autocomplete) │   │   │
│  │  └──────┬──────┘ └────┬─────┘ └────────┬─────────┘   │   │

             │             │                │

│                       SERVICE LAYER                          │
│  ┌─────────┴─────────────┴────────────────┴──────────────┐  │
│  │                   LLM Service                          │  │
│  │  ┌──────────┐  ┌──────────┐  ┌──────────────────┐    │  │
│  │  │ Provider  │  │ Prompt   │  │ Response         │    │  │

│  │  └────┬─────┘  └────┬─────┘  └────────┬─────────┘    │  │

      External LLM API   System Prompt    Streaming Output
```

### 4.2. Паттерны

- **Scene Graph:** QGraphicsItem с наследованием трансформаций
- **Signals/Slots:** Коммуникация между слоями через Qt-сигналы
- **Repository:** FileStore скрывает детали файлового I/O
- **Strategy:** LLM Service поддерживает разных провайдеров
- **Command (Undo/Redo):** Стек комманд для всех действий на холсте

```

```json
{
  "id": "edge_f7g8h9i0",

  "target_id": "b2c3d4e5-...",
  "label": "Требуется для",

**Изменения v2:**
- `line_style` — только `orthogonal` (Manhattan routing), Bezier удален

## 8. Требования к UI/UX

### 8.1. Концепция, цвета и типографика

#### 8.1.1. Цветовые палитры

Фирменный акцентный цвет для обоих режимов: **Santi (#743354)**.

**Темная тема (базовая):**
- Фон холста: `#1e1e2e`
- Фон сайдбаров и панелей: `#181825`
- Точки сетки: `#313244`
- Основной текст: `#cdd6f4`
- Акцент: `#743354`

**Светлая тема:**
- Фон холста: `#f4f4f7`
- Фон сайдбаров и панелей: `#ffffff`
- Точки сетки: `#e2e2e9`
- Основной текст: `#4c4f69`
- Акцент: `#743354`

#### 8.1.2. Типографика

- **Интерфейсный шрифт:** `Inter` или `SF Pro` (sans-serif для меню, настроек, кнопок)
- **Контентный шрифт:** `JetBrains Mono` или `Fira Code` (моноширинный для заголовков узлов, текста внутри боксов, тегов, всей панели чата)
- **Скругления:** 8px для карточек и панелей, 6px для мелких элементов (кнопки, инпуты, теги)

### 8.2. Архитектура окна

#### 8.2.1. Frameless-окно с кастомным Top Bar

- Окно без стандартных системных рамок (Frameless OS Window)
- Верхняя панель содержит: название проекта, кнопку переключения тем (Солнце/Луна), кнопки управления окном (свернуть, развернуть, закрыть)

```
┌──────────────────────────────────────────────────────────────────┐
│  [≡]  Название проекта     [🌙/☀️]  [─]  [□]  [✕]  │
├──────────────────────────────────────────────────────────────────┤
```

#### 8.2.2. Focus Mode

- `Ctrl+B` — скрывает левый и правый сайдбары
- Холст расширяется на 100% ширины окна
- Повторное нажатие возвращает панели

#### 8.2.3. Empty State

При пустом проекте по центру холста отображается плашка с шорткатами:

```
┌──────────────────────────────────────┐
│                                      │
│          Добро пожаловать в Sai       │
│                                      │
│   ⬡ Двойной клик — Создать узел      │
│   ✋ Space + Перетаскивание — Pan    │

### 8.6. Ортогональные линии (Edges)

- **Геометрия:** строгие ортогональные линии (Manhattan routing), только углы 90°

- **Управление:** пользователь может кликнуть на излом и изменить геометрию пути
- **Хитбокс:** невидимая область шириной 6px для захвата курсором
- **Запрет:** коллизии линий между собой и наложение на границы узлов
