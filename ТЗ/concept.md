## Суть продукта

**Sai** — это инструмент для размышления и визуализации проектов с помощью ИИ. Генерация ТЗ — приятный бонус, но не главная цель.

## Аудитория (широкая)

Все, кто связан с ИИ и разработкой:
- Соло-фаундеры
- Вайбкодеры
- Малые команды
- Разработчики, проектирующие архитектуру через ИИ

## Механика трёх деревьев

| Параметр | Решение |
|----------|---------|
| **Создание** | Все три дерева генерируются при первой синхронизации |
| **Обновление** | Только по кнопке «Синхронизация» — вручную, когда пользователь решит |
| **Каскад** | Изменения не летят автоматически. Пользователь контролирует момент синхронизации |
| **Независимость** | После синхронизации деревья можно редактировать независимо |

## Чаты и контекст
    
- **Чат узла** может менять только тот узел, с которого открыт
- **Память** — только история своего чата. Без кросс-чатного контекста
- Каждый чат изолирован и самодостаточен

## Экспорт ТЗ

Пользователь выбирает:
- Какие узлы включить
- Какие деревья включить (functional / development / business)
- Формат и наполнение — гибко, а не «одна кнопка»

## Платформа и будущее

- Сейчас: сугубо локальное десктопное приложение
- В планах: расширение (веб / облачная синхронизация / шаринг)
- Но конкретные сроки и форматы не определены
