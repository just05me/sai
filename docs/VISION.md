> **Версия продукта:** 1.0.0  
> **Лицензия:** LGPL

---

## 1. Суть продукта

**Sai** — браузерная рабочая среда для структурированного мышления: пользователь описывает идею, общается с ИИ и собирает **три связанных дерева знаний** (Разработка / Функции / Бизнес). Sai помогает на этапе «от идеи до структуры и ТЗ», но **не пишет код и не управляет людьми**.

Ключевой цикл:

1. Описать идею (текст, Quick Capture, шаблон).
2. Раскладывать идею на узлы и связи на бесконечном канвасе.
3. Работать в трёх деревьях одновременно; cross-tree bridges связывают модели.
4. Чат по узлу или глобальный чат с контекстом проекта.
5. ИИ предлагает изменения графа — **только с подтверждением пользователя**.
6. Экспорт ТЗ (Markdown, PDF, TXT, JSON, Mermaid) или share-ссылка.

Sai **не является**: IDE, Notion, Jira, Miro.

## 2. Релиз 1.0 (selfhost-only)

### 2.1. Золотой путь

**Создал проект → накидал узлы → поговорил с ИИ → выгрузил MD/PDF.**

Запуск: `docker compose up` или локально Postgres + `npm run dev`. Регистрация не нужна — **локальный пользователь** создаётся автоматически.

### 2.2. Что входит в 1.0

| Область | Реализация |
|---------|------------|
| Канвас | React Flow, три дерева DEV/FUNC/BIZ, bridge-связи |
| Mind Map | Переключение Graph ↔ Mind Map (d3-hierarchy layout) |
| Sync | Анализ несоответствий между деревьями, создание bridge |
| AI | BYOK, 5 персон, Expand/Refactor/Propose Tree, streaming chat |
| Экспорт | MD, TXT, JSON, Mermaid, **PDF** (@react-pdf/renderer) |
| Инфра | Postgres + pgvector, Docker Compose, seed шаблонов |
| Auth | Только local-user (без OAuth/cloud) |

### 2.3. Сознательно не в 1.0 (план 1.1+)

- Real-time collab (Yjs/Hocuspocus)
- Redis, BullMQ, email-очереди
- Stripe / cloud SaaS
- OAuth / magic-link
- Team AI Memory (RAG) — pgvector в БД оставлен для будущего

## 3. Архитектура

- **Frontend:** Next.js 15, React 19, tRPC, React Flow, Zustand
- **Backend:** tRPC + Route Handlers, Prisma, PostgreSQL
- **AI:** Vercel AI SDK, ProviderManager + BYOK (AES-256-GCM)
- **Deploy:** Docker standalone, миграции + seed при первом старте

---

## 4. Синхронизация деревьев

По кнопке «Синхронизация»:

1. DEV-узлы без bridge в FUNC → предупреждение
2. BIZ-узлы без bridge в DEV → предупреждение
3. Расхождение названий у bridge → предупреждение
4. Сиротские bridge → ошибка

Пользователь вручную создаёт bridge через UI (не автокаскад).

---

## 5. Критерии готовности 1.0

1. Чистая машина: `docker compose up` → рабочий продукт с шаблонами.
2. Золотой путь + Mind Map + sync + экспорт проходят вручную и в e2e-smoke.
3. CI зелёный: typecheck, lint, unit, e2e.
4. README / CHANGELOG / VISION соответствуют коду.
