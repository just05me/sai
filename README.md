# Sai — Память ИИ-сессий (claude_brain)

[![Branch](https://img.shields.io/badge/branch-claude__brain-purple)](https://github.com/just05me/sai/tree/claude_brain) [![AI](https://img.shields.io/badge/AI-Claude%20%2F%20Cursor-orange)](https://www.anthropic.com) [![Format](https://img.shields.io/badge/format-Markdown-blue)](https://www.markdownguide.org)

> Ветка с **логами и контекстом ИИ-сессий**, которые двигали проект Sai вперёд. Сохранённая память агента: что обсуждалось, какие решения принимались, какие подсказки сработали.

---

## Зачем эта ветка?

Когда работаешь с ИИ-агентом неделями подряд, **контекст теряется**. Каждая новая сессия — пустой лист. Эта ветка решает проблему:

- 🧠 **Brain** — снепшоты «мозга» агента: суммаризированный контекст и выводы
- 📜 **History** — хронологические логи: что просили, что отвечал, что получилось
- ♻️ **Восстановление контекста** — новая сессия читает свежие `brain/*.md` и сразу в курсе дел
- 🔍 **Аудит решений** — можно вернуться к моменту, когда было принято конкретное архитектурное решение

---

## Структура

```
claude/
├── brain/                  # Снепшоты контекста (что нужно знать агенту)
│   ├── 0.md                # Стартовая база знаний
│   ├── 1.md                # После сессии 1
│   ├── 2.md
│   ├── ...
│   └── 6.md                # Свежий снепшот
└── history/                # Хронология сессий
    ├── 0.md                # Сессия 0
    ├── 1.md
    ├── ...
    └── 8.md                # Последняя сессия
```

---

## Различие `brain/` vs `history/`

| | `brain/` | `history/` |
|--|--------|------------|
| Назначение | Что **знать сейчас** | Что **было раньше** |
| Объём | Сжатый, кураторский | Полный, сырой |
| Когда обновляется | После каждой сессии | По ходу сессии |
| Кто читает | Новый агент при старте | Аналитик / автор для аудита |

## Как пользоваться

### Начало новой ИИ-сессии

```bash
git clone -b claude_brain https://github.com/just05me/sai.git sai-brain
cd sai-brain/claude

# Скармливаем агенту свежий контекст
cat brain/6.md
```

### Поиск конкретного решения

```bash
grep -ri "архитектура чата" history/
```

---

## Принципы ведения

1. **Brain нумеруется монотонно**: новый снепшот = `brain/N+1.md`. Не редактируем старые.
2. **History — append-only**: каждая сессия пишется в отдельный файл, не правится постфактум.
3. **Markdown без выкрутасов**: заголовки, списки, блоки кода. Никаких бинарников.
4. **Без секретов**: API-ключи, пароли и токены сюда **никогда** не попадают.
