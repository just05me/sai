# Sai — Свалка (musor)

[![Branch](https://img.shields.io/badge/branch-musor-7d4a4a)](https://github.com/just05me/sai/tree/musor) [![Type](https://img.shields.io/badge/type-scratch-orange)](https://github.com/just05me/sai) [![Status](https://img.shields.io/badge/status-archive-lightgrey)](https://github.com/just05me/sai)

> Ветка с **черновиками, сырыми заметками и скриншотами** — всё, что родилось по дороге к Sai, но не попало в чистовик. Папка `AllOtherShit/` — приватный архив идей, не предназначенный для прод-репозитория.

---

## Зачем эта ветка?

Идеи, скрины интерфейсов, обрывки переписок и наброски не имеют места в основной ветке, но и выбросить их жалко — иногда там лежит **критичный контекст** того, *как именно* родилось решение.

- 🗃 Сохраняет «сырую» историю продукта
- 🧠 Контекст для возврата к старым решениям через месяцы
- 🚫 Изолирована от `main` — не засоряет основной репозиторий

---
