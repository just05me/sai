## Зафиксированные решения

1. **Суть продукта:** Инструмент для размышления и визуализации, а не генератор ТЗ. ТЗ — приятный бонус.
2. **Аудитория:** Широкая — все, кто связан с ИИ и разработкой (не только соло-фаундеры или вайбкодеры, а все вместе).
3. **Синхронизация деревьев:** Только по кнопке «Синхронизация», ручной контроль. Никакой автоматики.
4. **Жизненный цикл деревьев:** Создаются при первой генерации, обновляются только по запросу пользователя.
5. **Чат узла:** Может менять только свой узел. Не влияет на соседние.
6. **Память чата:** Только история своего диалога. Без перекрёстного контекста между чатами.
7. **Экспорт ТЗ:** Гибкий — пользователь выбирает узлы и деревья для включения.
8. **Платформа:** Локальный десктоп. В планах — расширение (веб/облако/шаринг), но без конкретики.
