# Brain Entry 2: Реализация продукта Sai v0.0.1

## Что было сделано
Создано полноценное десктопное приложение Sai v0.0.1 на Python + PySide6 в директории `/home/rizo/sai/versions/sai_0_0_1/`.

Приложение реализует Stages 1-7 из ТЗ (sai_0_0_2.md):
- Stage 1: Базовое окно (3 панели, тёмная тема)
- Stage 2: Бесконечный холст (QGraphicsScene + QGraphicsView)
- Stage 3: Узлы и связи (BoxNode, EdgePath с кривыми Безье)
- Stage 4: Data Layer (tree.json сохранение/загрузка)
- Stage 5: LLM Worker (QThreadPool + httpx, SettingsDialog)
- Stage 6: Context Chats (ChatPanel с node-scoped чатами)
- Stage 7: Генератор ТЗ (ExportService → Markdown)

## Ключевые архитектурные решения

1. **GraphEngine как QObject** — emits signals при изменениях, UI подписывается
2. **BoxNode как QGraphicsItem** — ItemIsMovable, ItemIsSelectable, ItemSendsGeometryChanges
3. **EdgePath через cubicTo()** — кривые Безье обновляются при перемещении узлов
4. **LLMService через QThreadPool+QRunnable** — не блокирует UI
5. **FileStore с atomic write** — write через tmp-файл + move
6. **Auto-save с debounce 1.5s** — QTimer.setSingleShot(True)

## Исправленные ошибки

1. **eventFilter в ChatPanel** — TypeError при вызове eventFilter с не-key событиями. Исправлено: проверка `QEvent.Type.KeyPress` + `hasattr(event, 'key')`
2. **setIconSize()** — ожидает QSize, не int. Исправлено: `QSize(16, 16)`
3. **setSizePolicy(2, 2)** — невалидные аргументы. Исправлено: `QSizePolicy.Expanding, QSizePolicy.Preferred`
4. **core/__init__.py** — импортировал `ProjectData` (несуществующий класс). Исправлено на `ProjectMeta`
5. **selection-background в QSS** — Qt6 требует `selection-background-color`

## Выводы

1. **Всегда использовать `QEvent.Type.KeyPress`**, не `event.KeyPress` — в PySide6 enum-типы вызываются иначе
2. **PySide6 строже к типам**, чем PyQt6 — `setIconSize(int)` не скомпилируется
3. **QSS в Qt6** — `selection-background` → `selection-background-color`
4. **Pydantic v2** — `model_dump()` вместо `dict()` (ломает обратную совместимость)
5. Приложение стартует без ошибок в offscreen-режиме — можно использовать для CI/CD
