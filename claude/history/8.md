## Key implementation details
- Dirty state tracked in GraphEngine via `_mark_dirty()` called from `_checkpoint()`, displayed as " ●" in title bar
- closeEvent shows 3-button dialog (Save/Discard/Cancel) when dirty
- Schema migration handles v0.0.3→v0.0.5: adds settings, cross_tree_edges, tree descriptors
- TemplateService stores in ~/.sai/templates/ as separate JSON files
- Provider keys stored per-provider in config, quick-switch in chat panel reconfigures LLM on message send
- Token count estimated as chars/4, displayed in chat panel
- Export formats: MD/TXT (via ExportService), PDF (via reportlab if available), PNG (canvas render)
- Cross-tree bridge double-click switches to target tree and centers on target node
