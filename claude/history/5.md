## [2026-05-24] hotkeys | Финальные фичи v0.0.3: hotkeys, recent projects, image export, undo/redo

### What was done
1. **GraphEngine**:
   - Добавлен `update_edge(edge_id, **kwargs)` — изменение label/edge_type у рёбер
   - Добавлен `duplicate_node(node_id)` — копирование узла со смещением 30px
   - Добавлен undo/redo: `_checkpoint()` перед каждой мутацией сохраняет полный слепок проекта. `undo()` / `redo()` восстанавливают состояние и эмитят `project_changed`
   - `_undo_stack` / `_redo_stack` — до 30 шагов каждый

2. **MainWindow**:
   - **Hotkeys**: Delete/Backspace → удалить выделенное, Ctrl+A → выбрать всё, Ctrl+D → дублировать узел, Ctrl+Z → undo, Ctrl+Y → redo
   - **Edit signals**: `node_edit_requested` → `engine.update_node`, `edge_edit_requested` → `engine.update_edge`, `node_updated` → синхронизация BoxNode, `edge_delete_requested` → `engine.remove_edge`
   - **Project changed**: `project_changed` → `_on_project_changed` → `_rebuild_canvas` + `_update_title` + синхронизация tree_switcher
   - **Recent projects**: В файловом меню подменю «Недавние проекты» (до 5), `_track_recent_project()` обновляет список, `_on_open_recent()` открывает проект
   - **Image export**: «Экспорт как PNG…» в файловом меню — рендерит QGraphicsScene в QImage и сохраняет
   - **Fix**: saveGeometry() теперь правильно конвертирует QByteArray → list[int] для JSON

3. **BoxNode**:
   - Удалён `mouseDoubleClickEvent` (конфликтовал с canvas.mouseDoubleClickEvent)
   - Очищен импорт (`QInputDialog`, `QMenu` удалены)

4. **Config**:
   - Добавлен `recent_projects: []` в DEFAULT_CONFIG
