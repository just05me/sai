ты мне нужен как советник для создания проекта назвал я его "Sai"

что это: 

это проект который помогает людям разрабатывать свои Проекта с помощью ИИ


- платформа где пользователь описывает свою идею, общается с ИИ и рассуждают над идеей. Делают браин шторм

- после рассуждения ИИ на основе выявленных данных создает "дерево решений" в котором будет: структура и логики продукта, фиксация функционала продукта


так он может заменить целую команду людей как: BSA | Product manager | project menejer | team lead


как происходит контакт и работа пользователя с Sai:

- пишет свою идею на чат с ИИ

- происходит рассуждение и браин-шторм

- ИИ в основе полученных данных создает дерево решений

- пользователь напрямую редактирует дерево и подстраивает под свои нужды

- получает готовое дерево для разработки продукта

- при необходимости может получить ТЗ для своего продукта от полученного дерево


что еще в проекте:

- есть 3 типа деревьев: Дерево разработки / Дерево функционала 
- Дерево функционала главная и в первую очередь пользователь работает с ним, остальные строються в основе дерево функционала
- каждое дерево строится вокруг значений друг друга и взаимосвязаны, при изменении одного другие тоже меняются
- у каждого чата с ИИ есть свои характеристики которые создаются автоматом: помять (храниться в отдельной папке и отмечается) / контекст / описание / логи
- при смене чата можно обращаться к придыдущим чатм для продолжение диалога
- дедает ресёрс через ИИ в сети для сбора данных по запросу пользователя и использует эти данные для разработки продукта
- дерево нужно для разработки логики / безнесс плана продукта


прислал тебе изображение в которм показана структура дерево и как она может быть устроена:
- каждый бокс = Функция / Вопрос 
- стрелка = Ответ / Путь / Причина ...

- у бокса есть: Значение / Описание / Путь / у пати есть Описание
- можно открывать каждый из боксов и создовать отдельный чат с ИИ в контексте этого бокса
